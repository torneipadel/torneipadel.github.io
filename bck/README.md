# Backup repository

Tutti i backup manuali vanno organizzati qui, senza lasciarli sparsi nella root del repository.

Struttura:
- `bck/bove/` — backup e riferimenti Bove
- `bck/whatsapp/` — copie blindate della funzione WhatsApp
- altre cartelle per aree future, se necessarie

Questi file sono copie di sicurezza e non vengono caricati dall'applicazione tramite `admin.html` o le altre pagine operative.
